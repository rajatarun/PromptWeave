# Examples

The repository skeleton does not yet implement prompt rendering or MCP tools. These files document **expected inputs** for future examples.

| File | Purpose | Runnable today? |
|------|---------|-----------------|
| [sample_intent.json](sample_intent.json) | Model-neutral intent fixture | No (data only) |
| [planned_render.sh](planned_render.sh) | Placeholder CLI invocation | Prints planned usage only |

When Phase 1 ships, this directory will gain scripts that call the library with **no network** (template-only rendering).
