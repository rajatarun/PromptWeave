# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.0.x (scaffold) | Best-effort on `main` only |
| &lt; 0.1.0 | No releases yet; use `main` at your own risk |

When `0.1.0` is tagged, this table will list supported minor versions.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

1. Use [GitHub private vulnerability reporting](https://github.com/rajatarun/PromptWeave/security/advisories/new) for this repository, **or**
2. Contact the repository maintainer through the channel listed on the GitHub profile / org security page.

Include:

- Description and impact
- Steps to reproduce
- Affected version or commit SHA
- Suggested fix (if any)

We aim to acknowledge reports within **7 days**. Fixing timelines depend on severity and release cadence for this early-stage project.

## Safe harbor

We support good-faith research that follows this policy and avoids privacy violations or service disruption.

See also [docs/security-notes.md](docs/security-notes.md).
